## 怎么跑

```bat
python demo.py                                     :: M1 自检
python run_aco.py data\solomon\100\c101.txt 3      :: M2：单个算例跑 3 次

```

## M4 消融实验：四个层级

| 层级 | 配置 | 对应创新点 |
| --- | --- | --- |
| L0 基线 ACO | η=1/距离，无精英/MMAS，无局部搜索 | 对照组 |
| L1 +时间窗 η | 加时间窗紧迫度与等待惩罚 | 创新点② |
| L2 +MMAS 精英 | 再加精英策略 + 信息素上下界 | 创新点③ |
| L3 +局部搜索 | 再加 2-opt / Or-opt / relocate = **改进版** | 创新点④ |

命令：`python run_experiments.py <规模> <重复次数> [算例名...] [--iters=N]`

## 首次真实实验结果（2026-10-09，1 次运行，30 迭代）

| 算例 | 已知最优 | L0 基线ACO | L1 +时间窗η | L2 +MMAS精英 | L3 改进版 |
| --- | --- | --- | --- | --- | --- |
| C101 | 828.94 | gap 104.9% | **0.0%** | 0.0% | 0.0% |
| C201 | 591.56 | gap 129.8% | **0.0%** | 0.0% | 0.0% |
| R101 | 1650.80 | 47.1% | 32.7% | 28.2% | **17.9%** |
| RC101 | 1696.95 | 47.5% | 33.6% | 28.1% | **17.1%** |

**结论**：C 类（聚类型）算例在 L1 就饱和到接近最优；**R / RC 类才能看出四个层级的梯度**——每一层都往下降，这就是消融实验最有说服力的证据。

## 实验规范（报告里必须遵守）

1. **每个算例每个方法至少跑 10 次**，报**均值 ± 标准差**（现在只跑了 1 次，std=0 是假象）
2. **覆盖六类算例**：C1 / C2 / R1 / R2 / RC1 / RC2 各取 2–3 个，不要只用 C 类
3. **固定随机种子**（脚本已固定 `seed = 1000 + 运行序号`，各方法用同一批种子 → 可配对比）
4. **gap 只对 100 客户算例算**（25/50 客户是从 100 客户派生的规模，没有对应的公认最优解）
5. **gap 到不了 0% 是正常的**：已知最优是长期元启发式跑出来的，课程项目重点讲"相对自己基线的提升"

## M3 可视化产出（`results/viz/`）

`python viz.py <算例> [--iters=N]` 一次生成：

| 文件 | 用途 |
| --- | --- |
| `<算例>_report.html` | **实验报告页**：指标表 + 路线图（按钮切换 5 个方法）+ 收敛曲线 + 消融图 + 参数表 |
| `<算例>_before_after.png` | 优化前后并排对比图（放报告/PPT 最合适） |
| `<算例>_NN/L0/L1/L2/L3_route.png/.svg` | 各方法的单张路线图 |
| `<算例>_convergence.png/.svg` | 收敛曲线 |
| `<算例>_ablation.png/.svg` | 消融柱状图（带 gap 标注） |

不依赖任何绘图库（SVG 用标准库拼、PNG 用 Pillow 画、中文用系统微软雅黑），**双击 HTML 即可查看，不需要起服务器、不需要联网**。
