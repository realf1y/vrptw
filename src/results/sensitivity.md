# 参数敏感性实验

- 迭代 40 代，每个参数组合 3 个随机种子（1/2/3）
- 目的：确定 α、β、ρ 的取值范围，为最终参数取值提供依据

## α × β 网格（算例 R101）

| α \ β | β=2 | β=3 | β=5 |
| --- | --- | --- | --- |

| α=2 | 1932.67 ± 9.99 | 1796.35 ± 35.96 | 1752.86 ± 19.68 |

## ρ 扫描（算例 RC101，α=1、β=3）

| ρ | 平均里程 | 标准差 |
| --- | --- | --- |
| 0.05 | 2076.45 | 28.31 |
| 0.1 | 1971.86 | 31.15 |
| 0.2 | 1909.24 | 50.33 |
| 0.3 | 1821.04 | 60.81 |

## 结论（由数据算出）

1. **α×β 最优组合：α=2、β=5**，平均里程 1752.86；最差组合 α=0.5、β=2，相差 24.4%。
2. 按 α 取平均：α=0.5 → 2022.1；α=1 → 1927.8；α=2 → 1827.3。本算例上 **α=2 最好**（里程越小越好）。
3. 按 β 取平均：β=2 → 2048.4；β=3 → 1920.5；β=5 → 1808.3。本算例上 **β=5 最好**（β 越大，启发式信息的权重越高）。
4. ρ 扫描：ρ=0.05 → 2076.4；ρ=0.1 → 1971.9；ρ=0.2 → 1909.2；ρ=0.3 → 1821.0。本算例上 **ρ=0.3 最好**，即该算例更依赖快速遗忘、避免过早收敛。

**注意**：敏感性只在单个算例上做，结论反映趋势，不等于全局最优；正式取值建议在 2–3 个算例上复核后再定。

当前主实验采用的参数为 α=1、β=3、ρ=0.1；若改用本实验给出的 α=2、β=5，解质量仍有下降空间，可作为后续调优方向。
